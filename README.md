# Startdocument Generator v2.4.5

Wijzigingen in deze versie:

- Belangrijkste arbeidsvoorwaarden worden uitsluitend via live webresearch bepaald.
- Alleen echte primaire/secundaire arbeidsvoorwaarden mogen door naar de slide.
- Werksfeer, cultuur, autonomie, impact, uitdaging, doorgroei, ontwikkelmogelijkheden en andere pullfactoren worden expliciet geblokkeerd.
- De research kiest exact 3 categorieën uit een vaste whitelist, zoals Salaris, Pensioenregeling, Vakantiedagen, Bonusregeling, Leaseauto, Mobiliteitsbudget, Reiskostenvergoeding, Thuiswerkregeling, Flexibele werktijden en Opleidingsbudget.
- Als de eerste websearch geen 3 geldige arbeidsvoorwaarden oplevert, volgt automatisch een strengere tweede websearch.
- Als er daarna nog steeds geen 3 geldige arbeidsvoorwaarden zijn, stopt de tool met een duidelijke foutmelding in plaats van verkeerde informatie te tonen.
- Alle eerdere v2.4.4-functionaliteit blijft behouden.

Upload alle bestanden en mappen opnieuw naar GitHub.
